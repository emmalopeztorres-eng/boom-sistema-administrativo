# BOOM – Gestión Integral

Sistema administrativo para una empresa de alquiler y venta de equipamiento de sonido e iluminación y prestación de servicios técnicos para eventos.

## Primera versión
- Panel general con indicadores y próximos eventos.
- Navegación por las áreas principales del negocio.
- Alta inicial de eventos, clientes y presupuestos.
- Persistencia de estos registros en el almacenamiento local del navegador.
- Diseño adaptable a computadoras, tablets y celulares.

## Módulos previstos
Agenda y eventos · Clientes · Presupuestos · Ventas y alquileres · Contratos · Inventario y equipos · Depósito y movimientos · Personal técnico · Logística y vehículos · Mantenimiento · Finanzas y caja · Proveedores y compras · Informes y estadísticas · Configuración.

## Cómo visualizar
Abrir `index.html` en un navegador. Para publicar con GitHub Pages: entrar en **Settings → Pages**, elegir **Deploy from a branch**, seleccionar `main` y `/ (root)`, y guardar.

## Importante
Esta etapa es un prototipo frontend. Los datos se guardan en el navegador mediante localStorage; todavía no hay base de datos central, inicio de sesión real, sincronización entre dispositivos ni facturación electrónica. Esas capacidades requieren backend y configuración de seguridad.
